Terakhir diperbarui: 18 Agustus 2026

01

Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana Suara Digital Desa ("Aplikasi", "Kami") mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan aplikasi kami. Kami berkomitmen untuk melindungi privasi dan keamanan data pengguna sesuai peraturan perundang-undangan yang berlaku di Republik Indonesia.

Dengan menggunakan Aplikasi ini, Anda menyetujui praktik yang dijelaskan dalam Kebijakan Privasi ini. Jika Anda tidak setuju dengan kebijakan ini, mohon untuk tidak menggunakan Aplikasi.

Aplikasi ini dirancang khusus untuk meningkatkan transparansi pengelolaan Anggaran Pendapatan dan Belanja Desa (APBDes) serta memfasilitasi partisipasi publik masyarakat desa.

04

Penyimpanan & Keamanan Data

Penyimpanan di Server

Semua data akun, aspirasi, program desa, dan dokumen disimpan di server kami yang dijalankan menggunakan Supabase, layanan backend open-source berbasis PostgreSQL yang aman.

Password tidak pernah disimpan dalam bentuk teks biasa. Seluruh autentikasi ditangani oleh sistem Supabase Auth yang menggunakan enkripsi dan hashing standar industri.
05

Penggunaan Data

Data yang kami kumpulkan digunakan semata-mata untuk tujuan berikut:

  • Autentikasi & Manajemen Akun — Memverifikasi identitas Anda, mengelola sesi login, dan menjaga keamanan akun
  • Pengiriman Aspirasi — Memfasilitasi pengiriman aspirasi, saran, dan keluhan dari warga kepada aparatur desa
  • Monitoring Program Desa — Menampilkan progress dan dokumentasi program pembangunan desa secara transparan
  • Transparansi Anggaran — Menyajikan data APBDes dan realisasi anggaran untuk diketahui publik
  • Sistem Notifikasi — Mengirimkan notifikasi terkait status aspirasi, update program, dan pengumuman desa
  • Penyediaan Layanan — Menjalankan dan memelihara fungsionalitas aplikasi
06

Pemberian & Berbagi Data

Kami tidak menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak ketiga mana pun.

Data Anda hanya dibagikan dalam situasi berikut:

  • Supabase (Penyedia Backend) — Data disimpan di server Supabase yang bertindak sebagai pemroses data atas nama kami.
  • Google Fonts — Font aplikasi dimuat dari server Google Fonts. Google hanya menerima nama font dan alamat IP Anda.
  • Kewajiban Hukum — Kami dapat membagikan data jika diwajibkan oleh hukum atau perintah pengadilan.
Aplikasi ini tidak menggunakan layanan analitik pihak ketiga seperti Google Analytics, Facebook SDK, atau layanan iklan apa pun.
07

Keamanan Data

Kami menerapkan langkah-langkah keamanan teknis dan organisasi untuk melindungi data Anda:

  • Enkripsi Transmisi — Semua komunikasi antara aplikasi dan server menggunakan protokol HTTPS/TLS
  • Enkripsi Penyimpanan — Token autentikasi disimpan menggunakan FlutterSecureStorage dengan enkripsi bawaan perangkat
  • Autentikasi Supabase — Menggunakan sistem autentikasi yang aman dengan hashing password standar industri (bcrypt)
  • Akses Terbatas — Data hanya diakses oleh sistem yang diperlukan untuk menjalankan layanan
  • Logging Debug — Logging hanya aktif dalam mode pengembangan (debug) dan tidak mengumpulkan data pengguna
08

Hak Pengguna

Sebagai pengguna Aplikasi, Anda memiliki hak berikut terkait data pribadi Anda:

  • Hak Akses — Anda dapat meminta informasi tentang data pribadi yang kami simpan tentang Anda
  • Hak Perubahan — Anda dapat memperbarui atau mengubah data profil Anda langsung melalui aplikasi
  • Hak Penghapusan — Anda dapat meminta penghapusan akun dan data pribadi Anda dari sistem kami melalui halaman penghapusan akun
  • Hak Portabilitas — Anda dapat meminta salinan data pribadi Anda dalam format yang dapat dibaca mesin
  • Hak Penarikan Persetujuan — Anda dapat menarik persetujuan penggunaan data pribadi Anda kapan saja
09

Anak di Bawah Umur

Aplikasi ini tidak dikhususkan untuk anak di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak di bawah umur. Jika Anda adalah orang tua atau wali dan mengetahui bahwa anak Anda telah memberikan data pribadi kepada kami, silakan hubungi kami agar kami dapat mengambil tindakan yang diperlukan.
